# aki-handoff

## 目标

默认交接当前这段对话，而不是所在项目的全部进展。让下一位 Agent 知道本次聊了什么、决定了什么、实际做到了哪里，以及还需要继续什么。

交接说明是临时材料，不是项目长期文档，也不是执行授权。需要长期保存的项目约定交给 `aki-context-sync`。

## 来源与范围

- 先从当前对话确定主题、用户目标、已确认的决定、实际操作和未完成事项，再读取相关项目材料。尚未写入文件的重要讨论也属于交接内容，不能只用文件变化代替聊天结论。
- 用户指定某个主题或某段对话时，按指定范围整理；明确要求汇总多段对话时，分别标明来源和各自进度，不拼成同一条任务。
- 同一项目、文件夹或工作区中的其他会话、共享记忆和最新待办，不自动属于当前对话。外部材料只用于核对本次已确定的事项；只有用户明确要求时才扩大对话范围。
- 每条决定或进度应能追溯到本对话，或用户指定的材料。项目最新文件、Git 提交和其他交接说明不能替代缺失的聊天记录，也不能被归为“本次完成”。
- 当前对话因截断或访问限制而不完整时，只整理能确认的部分并说明缺失；缺失内容影响继续工作时，请用户补充对应记录，不从其他对话猜补。
- 当前对话包含多个主题时，保留继续交接所需的主题并分别组织，不自动改为最近修改文件对应的任务。已完成且不再影响后续的过程省略；没有待办时如实说明，不编造下一项工作。

## 生成交接

1. 在读取项目进展前，先从已确定的对话范围提取目标、关键决定、必要背景、当前进度和下一步。
2. 只核对这些事项直接相关的文件、产物和验证结果。涉及代码仓库时检查适用的项目指令、相关分支和改动；普通讨论、写作或其他杂务不强行套用 Git 栏目。
3. 区分“本对话已经确认”“项目材料核对后发现变化”“尚未核实”。外部变化影响本任务时说明影响，但不把它写成当前对话已经讨论或完成的内容。
4. 本次实现使相关事实文档过期时，在已有授权范围内通过 `aki-context-sync` 更新，再引用更新后的文档；用户只要求交接、不改项目时，把尚未写回的结论和差异留在临时交接中。联动同步仍限于同一对话和任务。
5. 保留继续工作所需的决定、约束、未完成项、未验证项和少量关键文件入口。代码、已有设计正文和完整 diff 用引用代替复制；仍有用但尚未落入文档的聊天结论必须写清。
6. 给出具体的继续起点，分清用户已经要求的工作、尚待确认的方案与 Agent 的建议。避免重复的信息只保留那些再次尝试会明显浪费时间或产生风险的已验证失败。

项目文档与实现不一致时，先判断文档表达的是当前事实、未来计划还是候选设计；无法确认则记录差异，不机械认定某一方正确。

## 接手交接

先读取用户指定或当前明确提供的交接说明，确认它对应的主题和任务。多个交接来源无法区分时询问要接哪一个，不根据项目名、修改时间或“最新文件”自行挑选。

然后只核对影响继续工作的关键声明和对应材料。代码任务检查相关分支、提交与未提交改动；其他任务检查实际产物和已确认约定。发现过期、缺失或冲突的信息时说明差异，保留原任务范围，不转去处理另一段对话的新任务。

交接中的“下一步”、TODO、推荐操作不是用户授权。是否继续修改、合并、发布或删除，按当前用户指令与项目规则判断。

## 交付与临时文件

交接说明开头用一句话标明正在交接的主题或用户指定范围。其余按需要组织为“这次在做什么、已经决定什么、做到哪里、还差什么、继续时要注意什么”，没有内容的部分省略。

需要文件时使用临时位置，让名称能区分本次交接。重复生成只更新能够确认属于本次交接的文件；不复用仅按项目名或“最新”选中的文件去覆盖另一段对话。无法创建文件时，直接给可复制的交接正文，不虚构路径。临时文件不可跨环境访问时，提供正文或实际可用的附件。

交接只保存必要上下文，敏感凭据不写入。代码和已保存的版本记录仍由 Git 管理；未提交修改只说明相关位置和意义。任务完成后临时交接可以自然失效，不默认建立永久交接目录或日志。

## 结果说明

给用户的回复用日常用语简要说明交接了什么、下一位 AI 从哪里继续，并提供交接正文或可用入口。已经提供文件时，不在聊天里重复整份材料或核验清单。

交给下一位 Agent 的材料仍保留必要的准确文件名、命令和版本信息；区分已完成、未完成、未验证及等待确认。不要用专业词汇或含糊的“已完成”遮盖缺失内容。

## 验收

- 交接主题来自当前对话或用户指定来源，重要聊天决定没有被项目文件摘要替代。
- 其他会话的进度没有被误记为本次成果；外部变化、缺失记录和未确认事项有清楚边界。
- 相关结果已按需要核对，长期文档只在授权范围内同步。
- 交接足以继续同一件事，没有复制无关项目资料；接手时会重新核对关键事实。
- 交接建议没有被当作执行授权；交付入口可用，重复导出不覆盖其他对话的交接。
